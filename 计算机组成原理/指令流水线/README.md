## 模拟器的时序约定

模拟器按 408 统考的口径建模，以下约定决定了图中每一格的位置：

- 5 段流水线 IF、ID、EX、MEM、WB，每段 1 个时钟周期；按序发射、按序完成，每段同一时刻只容纳一条指令。
- **无转发**：后续指令在 ID 段读寄存器，必须在前一条指令 WB 之后；默认同一寄存器的读写不能在同一周期，勾选“前半周期写、后半周期读”后 WB 与 ID 可以重叠。阻塞格画在 IF 与 ID 之间，与真题答案表格一致。
- **转发**：ALU 结果在 EX 段末可用（经 EX/MEM 或 MEM/WB 转发），load 结果在 MEM 段末可用，因此 load-use 仍需阻塞 1 个周期，阻塞格画在 ID 与 EX 之间。开启转发时默认寄存器堆前写后读。
- **控制冒险**：beq / bne 在 EX 段比较、MEM 段末写 PC，后续指令要等到下一周期才能取指（延迟 3 个周期）；j 在 EX 段更新 PC（延迟 2 个周期）。可选“静态预测不跳转”，预测失败时冲刷已取入的错误路径指令。
- **插入 nop 模式**：由编译器在相关指令前、分支指令后插入 nop，代替硬件阻塞。
- **结构冒险**：勾选“指令和数据共用一个存储器”后，IF 不能与 load / store 的 MEM 在同一周期。
